# hms-micita-salud--Gutierrez-Bola-os-
Parcial Procesos de Modelado de Software
MiCita Salud
Descripción
Proyecto de modelado funcional de la plataforma MiCita Salud para la asignatura Herramientas de Modelado de Software de la Universidad de Santander (UDES).

El proyecto tiene como objetivo representar los requisitos funcionales de la plataforma mediante un diagrama de casos de uso utilizando UML.

Integrante
Andres Farit Gutierrez Bolaños

Herramienta de modelado
Lucidchrart

Justificación de la herramienta
Se eligió Lucidchrart porque permite crear diagramas UML de una manera sencilla y organizada. Además, cuenta con los elementos necesarios para realizar el diagrama de casos de uso solicitado en esta actividad, como actores, casos de uso, asociaciones, generalización, «include» y «extend». También permite exportar los diagramas y guardar el archivo fuente del modelo.

Como alternativa se consideró Visual Paradigm Community, que también permite trabajar con UML y tiene varias herramientas para el modelado de software. Sin embargo, se escogió StarUML porque tiene una interfaz más sencilla para el trabajo que se necesita realizar en esta actividad y resulta más fácil de utilizar para construir y modificar el diagrama de casos de uso.
